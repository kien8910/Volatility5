# Transformer prototype cross-attention V2

This experiment replaces the first cross-attention attempt while preserving
its outputs. It still uses the old daily FinTexTS embedding/prototype pipeline
and does not require LLM or structured-event extraction.

## Why V2 is different

The first experiment jointly relearned the centre price forecast. Its neural
price head was weaker than Ridge, so the comparison mixed price-model quality
with the value of attention.

V2 freezes the strongest centre forecast:

```text
fold-safe R6-Ridge centre forecast
        +
Transformer prototype residual correction
```

Train residuals are generated by an expanding-window OOF R6-Ridge model.
Validation is predicted by a final R6-Ridge fitted on the complete outer-train
fold. The correction model never receives fitted in-sample residual targets.

## Transformer architecture

```text
Price/HAR scalar tokens + ticker context + optional metadata token
                         |
             Transformer self-attention encoder
                         |
                    Query sequence (Q)

Prototype identity + news-level embedding + soft activation
                         |
                 Prototype memory (K, V)

Q -> multi-head cross-attention(K, V)
  -> residual Add
  -> LayerNorm
  -> position-wise GELU FFN
  -> residual Add
  -> repeat for configured cross-attention layers
  -> gated residual correction
```

The implementation uses separate query and memory normalization, true
multi-head Q/K/V projection, key padding masks, residual connections,
LayerNorm and Transformer FFN sublayers.

The gate is initialized at `0.05` and the correction output at zero. Training
therefore starts from the frozen R6-Ridge prediction rather than destroying a
strong baseline.

## Fixed comparisons

- `PRICE_RIDGE`
- `PRICE_META_RIDGE`
- `R6_RIDGE`: frozen centre forecast
- `META_RESIDUAL_MLP`
- `R6_RESIDUAL_CONCAT_MLP`
- `R6_TRANSFORMER_XATTN`: Transformer without the metadata query token
- `R6_META_TRANSFORMER_XATTN`: primary model
- `R9_META_TRANSFORMER_XATTN`: random-prototype memory
- `R10_META_TRANSFORMER_XATTN`: shuffled-date memory
- `R11_META_TRANSFORMER_XATTN`: shuffled-ticker memory

All true-news and placebo Transformer models use the exact same frozen
R6-Ridge centre forecast. Only the prototype memory changes.

## Prerequisite

The server must contain the existing fold-safe R6/R9/R10/R11 artifacts:

```bash
python fintexts_semiconductor_prototype/run_pipeline.py \
  --stage r6-confirmatory \
  --config fintexts_semiconductor_prototype/config/config_r6_confirmatory.yaml
```

## Smoke run

```bash
python original_volatility_targets/run_prototype_transformer.py \
  --stage plan --quick

python original_volatility_targets/run_prototype_transformer.py \
  --stage train --quick --resume

python original_volatility_targets/run_prototype_transformer.py \
  --stage evaluate --quick
```

The quick run is technical only because it does not include every fixed
comparison, fold and seed.

## Full validation

```bash
python original_volatility_targets/run_prototype_transformer.py \
  --stage all --resume
```

The default grid has:

```text
10 models x 3 chronological folds x 5 paired seeds = 150 tasks
```

Run selected cells by repeating `--model`, `--fold` or `--seed`:

```bash
python original_volatility_targets/run_prototype_transformer.py \
  --stage train \
  --model R6_META_TRANSFORMER_XATTN \
  --fold 1 \
  --seed 11 \
  --resume
```
